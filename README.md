# Sales Data Analysis using SQL

## 📌 Project Overview

This project analyzes sales data using SQL to find useful business insights about employees, products, departments, and regions.

The project was created using MySQL and focuses on practical SQL queries used in data analysis.

## 🛠️ Tools Used

* MySQL
* MySQL Workbench
* SQL

## 📊 Dataset

The dataset contains 15 sales orders with the following columns:

* Order ID
* Order Date
* Employee Name
* Department
* Product
* Region
* Quantity
* Unit Price

## 🔍 SQL Concepts Used

* SELECT
* WHERE
* ORDER BY
* LIMIT
* SUM()
* AVG()
* COUNT()
* GROUP BY
* HAVING
* CASE
* Subqueries
* Calculated Columns

## 📈 Analysis Performed

The project answers questions such as:

1. What are the total sales?
2. How much sales did each employee generate?
3. Which product generated the highest sales?
4. Which region generated the most sales?
5. How much sales did each department generate?
6. Which employees had total sales above ₹1,00,000?
7. What is the average order value?
8. Which order had the highest sales value?
9. How many units of each product were sold?
10. What percentage of orders were High, Medium, or Low value?
11. Which employees had sales above the average employee sales?

## 🎯 Project Objective

The objective of this project is to practice intermediate SQL skills and understand how SQL can be used to analyze sales data and answer real-world business questions.
